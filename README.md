# VoiceCast

Плагин для Purpur/Paper 1.21 и Simple Voice Chat 2.6: игрок произносит фразу в микрофон, и срабатывает способность; боссы говорят голосом.

## Сборка через GitHub
1. Создай на github.com новый репозиторий и загрузи в него всё содержимое этой папки (включая `.github`).
2. Открой вкладку Actions, дождись зелёной галочки у сборки `build`.
3. Зайди в сборку и скачай артефакт `voicecast` - внутри `voicecast-1.0.0.jar`.
4. Положи jar в папку `plugins` сервера и перезапусти сервер.

## Первый запуск
Плагин сам скачает русскую модель распознавания (около 45 МБ) в `plugins/VoiceCast/model`.
Фразы настраиваются в `plugins/VoiceCast/config.yml`, после правки: `/voicecast reload`.

## Голос боссов
Положи файл `plugins/VoiceCast/voices/<имя>.wav` (PCM 16 бит). Когда датапак вешает на босса тег `bv_<имя>`, плагин проигрывает этот файл рядом с боссом.
Проверка: `/voicecast play <имя>`.

## Команды
- `/voicecast on|off` - включить или выключить распознавание для себя
- `/voicecast reload` - перечитать настройки (админ)
- `/voicecast play <имя>` - проиграть звук рядом с собой (админ)
